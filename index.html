Build Sequence

7-Phase Pipeline

Each phase builds on the previous. From prerequisite setup through design, motion, spatial architecture, and iterative refinement.

P0

Prerequisite

Install all 4 core skills. Scaffold Next.js project with TypeScript and Tailwind CSS.

npx skills add <owner>/<repo> --skill <name>
P1

Design System

UI/UX Pro Max generates design-system/MASTER.md and tokens.css. Typography, color palette, spacing rhythm.

design-system/MASTER.md + tokens.css
P2

Motion Vocabulary

3-tier motion system: Macro (400-600ms, page transitions), Meso (200-350ms, component), Micro (80-150ms, micro-interactions).

src/lib/motion.ts
P3

Spatial Architecture

4 depth layers: Background (z-0), Context (z-10), Content (z-20), Interaction (z-30). Z-axis hierarchy with glass depth.

src/lib/spatial.ts
P4

Generation Seed

Stitch Loop config files. Design tokens, site map, and component specifications for autonomous generation.

.stitch/DESIGN.md + .stitch/SITE.md
P5

Iterative Refinement

Audit loop with scoring. Target ≥85/100. Automated quality gates for performance, accessibility, and visual consistency.

.stitch/AUDIT.md
P6

Integration Wiring

PromptOS Provider, HERMES Silent Protocol, Command Palette (Cmd+K), Workflow Builder (Composer → Diff → Score → Basket).

src/providers/promptos.ts + src/lib/hermes.ts
Zones

5-Zone Architecture

Each zone serves a distinct purpose in the PromptOS workflow — from activation through monetization.

⚡ ACTIVATE — #4DFFFF

The prompt-writing zone. Where users compose modifiers, sauces, and workflows to activate the build pipeline.

Modifiers

Contextual overrides that shape AI behavior per prompt.

Sauces

Pre-built prompt templates for common patterns.

Workflows

Multi-step prompt chains with conditional logic.

Silent Protocol

Pre-response diagnostic layer — 3 questions before every answer.

🔧 BUILD — #FF6B00

The implementation zone. Workflow Builder pipeline: Composer → Diff → Score → Basket.

WF Builder

Compose, diff, and score changes before applying them.

Diff Engine

Visual diff of proposed changes with line-level granularity.

Score Gate

Automated quality scoring — must pass threshold to proceed.

Basket

Staged changes queue. Review, approve, or reject in batch. Cmd+B.

✅ VALIDATE — #22c55e

Quality assurance zone. Lint rules, performance budgets, accessibility checks.

Lint Rules

Custom ESLint + Tailwind rules for PromptOS conventions.

Quality Gates

Automated checks: bundle size, Lighthouse score, type safety.

A11y Checks

WCAG 2.1 AA compliance validation on every build.

Visual Regression

Screenshot diffing for critical UI paths.

Installation

Installation Guide

Get PromptOS running in under 5 minutes.

Install Skill CLI

The skills CLI manages installation and lifecycle of all PromptOS skills.

npm install -g @anthropic/skills-cli

Install Core Skills

Run all 4 core skill installs in sequence.

npx skills add nextlevelbuilder/ui-ux-pro-max-skill --skill ui-ux-pro-max && \
npx skills add 21st-dev/registry --skill 21st-registry && \
npx skills add google-labs-code/stitch-skills --skill stitch-loop && \
npx skills add patricio0312rev/skills --skill framer-motion-animator

Scaffold Project

Create a new Next.js project with TypeScript and Tailwind CSS.

npx create-next-app@latest promptos-app --typescript --tailwind --eslint --app --src-dir

Initialize PromptOS

Run the initialization script to set up design system, motion, and spatial configs.

cd promptos-app && npx skills run promptos-init

Start Development

Launch the dev server and open PromptOS in your browser.

npm run dev
Known Issues

Known Errors & Fixes

Current known issues and their workarounds.

HIGH Skill install fails on Node 22

▼

Symptom: npx skills add exits with ERR_MODULE_NOT_FOUND on Node.js 22.x.

Workaround: Use Node.js 20 LTS. Run nvm use 20 before installing skills.

Fix ETA: Patch expected in next CLI release.

MED Stitch Loop audit hangs on large projects

▼

Symptom: Audit loop times out when project exceeds 500 files.

Workaround: Run stitch-loop --max-files 200 to limit scope, or exclude node_modules and .next in stitch config.

Fix ETA: File-size batching in next Stitch Loop update.

MED HERMES Protocol not detecting zone context

▼

Symptom: Silent Protocol badge doesn't appear when typing in WF Builder.

Workaround: Ensure HERMES_ENABLED=true in .env.local. Check that the PromptOS Provider is wrapping the root layout.

Fix ETA: Auto-detection fix in PromptOS v1.1.

LOW 21st.dev publish fails silently

▼

Symptom: Component publish returns success but doesn't appear in team registry.

Workaround: Run 21st-registry --verbose to check for auth errors. Re-authenticate with 21st-registry login.

Fix ETA: Auth token refresh fix pending.

LOW Motion tokens not applying to Framer Motion 11

▼

Symptom: Custom motion tokens in motion.ts ignored by Framer Motion components.

Workaround: Import tokens explicitly: import { tokens } from '@/lib/motion' and pass as transition prop.

Fix ETA: Auto-injection plugin in development.
